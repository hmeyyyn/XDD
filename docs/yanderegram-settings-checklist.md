# Windows: проверка новых настроек

Использовать два тестовых аккаунта. Все шесть параметров по умолчанию выключены.

- **Журнал.** Включить только сохранение правок. С другого аккаунта прислать `один`, изменить на `два`, затем на `три`. В настройках → Сообщения → Журнал должны появиться две прежние версии с одним номером сообщения. Затем включить сохранение удалений и удалить сообщение у обоих: в чате оно исчезает, в журнале остаётся `три`. Повторить в группе/канале. Дубликат обновления без изменения текста не должен добавлять запись. Исчезающий текст и защищённые сообщения не должны сохраняться. Перезапустить клиент, проверить изоляцию аккаунтов, очистить журнал и вновь перезапустить. Старые сборки без поля журнала должны загружать пустой журнал без сброса остальных настроек.
- **Призрак.** Включить во время активной сессии, в том числе при включённом чередовании статуса. Проверить со второго аккаунта набор, запись голоса и загрузку файла. После выключения индикаторы должны вернуться. Режим не отключает доставку, прочтения и не управляет другими сессиями.
- **Счётчики.** Открыть заново пост с 12 345 просмотрами после переключения. Число должно быть полным; после выключения — сокращённым. Проверить реакции и пересылки.
- **Последний визит.** Проверить профиль и заголовок диалога для точного времени (минуты, часы, дни), онлайн, бота и скрытого статуса. Последний случай не должен превращаться в точное число.
- **Стикеры.** Использовать больше разных стикеров, чем вмещает серверный список. Проверить после обновления списка и перезапуска: облачные недавние сверху, затем локальные, без повторов. Очистить недавние и убедиться, что старый список не вернулся.
